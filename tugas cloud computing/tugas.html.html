Peran Stakeholder Pengelolaan & Keamanan Data pada Layanan SaaS

Dalam ekosistem Software as a Service (SaaS), mitigasi risiko keamanan data bergantung pada pembagian tanggung jawab yang jelas antara tiga pemangku kepentingan utama:

  • Pemilik Data (Data Owner): Individu atau entitas yang memiliki hak legal atas data pribadi/sensitif yang dikumpulkan dan berhak menentukan izin penggunaannya.
  • Pengendali Data (Data Controller): Organisasi/perusahaan pengguna layanan SaaS yang menentukan tujuan dan cara pemrosesan data milik pengguna akhir.
  • Prosesor Data (Data Processor): Penyedia layanan cloud/vendor SaaS yang menyimpan, memproses, dan mengamankan infrastruktur data atas nama Pengendali Data.

1. Aplikasi Cloud: Reservasi Hotel

Stakeholder Pihak Terkait Peran & Mitigasi Keamanan Data
Data Owner Tamu / Pelanggan Hotel Pemilik asli data identitas (KTP/Paspor), kontak, riwayat menginap, dan detail kartu pembayaran. Berhak meminta penghapusan atau koreksi data pribadi.
Data Controller Manajemen / Perusahaan Hotel Menentukan data tamu apa saja yang dikumpulkan untuk proses check-in dan promosi, serta memastikan kepatuhan regulasi perlindungan data (UU PDP/GDPR).
Data Processor Vendor SaaS PMS / OTA (mis. Cloudbeds, SiteMinder) Menyediakan server cloud, melakukan enkripsi transaksi pembayaran (standar PCI-DSS), pencadangan rutin, dan kontrol akses berbasis peran (RBAC) bagi staf hotel.

2. Aplikasi Cloud: SIM Rumah Sakit (SIMRS)

Stakeholder Pihak Terkait Peran & Mitigasi Keamanan Data
Data Owner Pasien Pemilik sah rekam medis elektronik (RME), hasil laboratorium, riwayat penyakit, dan data asuransi yang bersifat sangat rahasia.
Data Controller Pihak Manajemen Rumah Sakit / Klinik Mengatur kebijakan privasi medis, persetujuan tindakan (informed consent), dan otorisasi dokter/perawat mana yang boleh mengakses rekam medis tertentu.
Data Processor Penyedia Layanan Cloud SIMRS Menjamin kerahasiaan data medis dengan enkripsi end-to-end, audit log setiap perubahan rekam medis, dan disaster recovery agar layanan medis tidak terhenti.

3. Aplikasi Cloud: Perbankan (Core Banking / Digital Banking)

Stakeholder Pihak Terkait Peran & Mitigasi Keamanan Data
Data Owner Nasabah Bank Pemilik data finansial, saldo rekening, riwayat mutasi, biometrik, dan kredensial autentikasi (PIN/OTP).
Data Controller Institusi Perbankan Mengelola kepatuhan terhadap regulasi otoritas keuangan (OJK/BI), menetapkan aturan verifikasi KYC, dan memantau deteksi penipuan (fraud detection).
Data Processor Vendor Cloud Banking / Penyedia Infrastruktur Menyediakan keamanan tingkat tinggi (ISO 27001, HSM untuk manajemen kunci kriptografi), proteksi DDoS, serta isolasi data antar-tenant (multi-tenancy isolation).
